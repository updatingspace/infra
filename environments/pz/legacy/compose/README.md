# Архив прежнего PZ Docker Compose

Эти конфигурации и скрипты сохранены для разбора истории миграции. Рабочие
сервисы описаны в `../../kubernetes`, а исходник текущего игрового образа —
в `../../runtime/game`. Символьная ссылка `stack/runtime` ведёт к нему, второй
копии кода нет. Старые collector dashboards здесь не являются источником Monium;
актуальны `../../observability/dashboards`.

`deploy-observability.py.disabled` не запускать: это старый Compose deployment,
его пути больше не соответствуют размещению IaC. Исторические README и команды
в этом каталоге описывают состояние до Kubernetes. Для восстановления через
Compose потребуются отдельный план, проверенные образы и остановка всех
Kubernetes-писателей. Нельзя запускать обе системы на одном мире.
