# Очистка после миграции — 30 сентября 2026

Выполнена на действующей VM `51.250.40.253`, без перезапуска Kubernetes-приложений.

## Результат

- Удалены четыре остановленных контейнера Compose, шесть старых all-in-one
  образов, четыре дублирующих Docker-образа и неиспользуемый build cache.
- Docker daemon/socket и отдельный системный containerd остановлены и отключены
  в systemd. K3s использует собственный containerd; он продолжает работать.
  Пакеты Docker оставлены установленными для возможного восстановления архива.
- Исходные конфиги и старые секретные env перемещены только внутри VM в
  `/opt/pz-stack/legacy-compose-20260930/` (0700). Они не экспортировались.
- Чистый выигрыш, включая место нового архива образов: **3.23 GiB**.
  На корневой ФС свободно **18.68 GiB**, занято около **67.5%**.
- Игровая ФС не менялась: свободно **4.03 GiB**, занято **84.1%**. Очистка Docker
  освобождает корневой диск, но не увеличивает лимит отдельного игрового раздела.

## Что сохранено

Все `/opt/pz-stack/data/*` и их назначения `/srv/pz-storage/*`, loop-файлы,
сейвы, рабочие образы K3s, Kubernetes Secrets, Terraform states/private vars,
provider mirror, журналы применения и автоматического обновления панели.
Полный проверенный архив `/var/backups/pz-k3s-20260930/pz-stack.tar.gz`
не изменён; внешней копии мира пока нет.

Перед удалением дублирующих образов сделан компактный архив на этой же VM:
`/var/backups/pz-k3s-20260930/legacy-images.tar.gz`, 395880997 bytes, root0600.
SHA256: `13b99dccf0e33ad8b7bafef79105c76212f31a41f4897c719e087e24f9ef68c7`.
Проверены 46 OCI blobs, наличие config/layers, четыре config digest и readback
SHA всего архива. Пробный `docker load` не выполнялся.

Архив содержит прежнюю панель 1.3.7; это не обещает совместимость с текущей

требует отдельной проверки и остановки всех писателей перед возвратом.
